# Images

原本をprivate R2へ先に保存し、登録は画像処理を待たない。端末上で向きを補正し、4:5のオフホワイトcanvasに中央配置して、960px表示画像と360px thumbnailをR2へ戻す。

AI背景除去（ONNX）は精度・サイズ・クラッシュリスクの理由で削除した（ADR-006）。四隅がほぼ同色かつ明るい場合だけ、画像端につながる背景色を保守的に透明化して前景を切り出す。床・木目・カーペットなど均一でない背景は除去せず、元の構図を保って4:5へ正規化する。処理に失敗した場合は原本を表示する。詳細画面では原本と整えた画像を切り替え、再処理できる。原本・表示用・thumbnailは別R2 keyで保持する。
