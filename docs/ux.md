# Wardrobe UX

ログイン後はクローゼットへ直行する。2列を標準に2/3/4列を保存でき、4:5画像、ブランド、商品名の順で表示する。カテゴリは横スクロール、検索はAppBar内、複合filterはbottom sheet、sortはmenuで完結する。

Drift cacheを先に表示してから同期し、refresh中や通信エラーでも既存一覧を消さない。画像領域を固定してlayout shiftを防ぎ、detailは同じnavigation stackに積んでscroll位置を保持する。登録後は完了画面を挟まず一覧へ戻す。

## 登録の速さ（写真から20秒）

写真から登録するときの入力負担を減らすため、エディタは「写真・商品名・カテゴリ・保存」だけを見せる構成にしている。

- 詳細（カラー表記、サイズ、価格、購入日、型番、SKU、購入店、メモ）は「詳細を入力」に畳む。開かなくても保存できる
- 保存はAppBarと本文末尾の両方にあり、スクロールしないと押せない状態を避ける
- 写真を選んだ直後に商品名へフォーカスし、キーボードを開く
- カメラ/ライブラリの選択は記憶し、2回目以降はシートを出さずに前回の方法で開く
- 保存後はスナックバーの「続けて撮る」で次の1枚に進める
- **カテゴリは選ばせない**。名前から `POST /api/classify` で推定して埋め、誤りはチップを1タップで直せる（未選択のまま保存することも可能）
